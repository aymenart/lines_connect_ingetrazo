# Lines Connect for IngeTrazo

**Lines Connect** is a professional 3D CAD extension for [IngeTrazo](https://ingetrazo.com), inspired by classic architectural edge connection and extension tools.

Developed by **Aymen Alhaddad (Architect & Developer)**.

## Features

- **Connect Edges**: Bridge closest endpoints or intelligently connect to the body of a transverse line (T-junction) with automatic edge splitting.
- **Extend to Corner / Line (Fillet R=0)**: Extend lines to meet cleanly at their 3D intersection. Zero overlapping lines.
- **Close Gaps**: Batch close open endpoints and small gaps across multiple selected edges.
- **Arc to Circle**: Complete any circular arc into a full 360-degree closed circle along its natural curvature.

## Installation

Install directly inside IngeTrazo via **Extensions ▸ Manage extensions… ▸ Lines Connect**, or download the release zip and extract it into `%APPDATA%\IngeTrazo\plugins\lines_connect`.
